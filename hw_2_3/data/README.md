# Наборы данных

`demo` — стандартный набор для трёх запланированных запусков DAG. Он содержит 6 000 событий 100 пользователей; полный объём не требуется генерировать заново. `campaigns.csv` взят без изменений из первой задачи ДЗ 2.2.

Команда воспроизведения из корня комплекта (Python 3.9+):

```bash
python3 scripts/generate_event_log.py \
  --rows 6000 --users 100 --change-probability 0.20 \
  --seed 42 --start-time 2026-01-01T00:00:00Z --max-step-seconds 900 \
  --rows-per-file 1000 --output-dir data/demo/events --overwrite
```

Шаг времени в компактном наборе увеличен специально: небольшое число строк покрывает январские рассылки. `events/_manifest.json` содержит параметры и временной диапазон генерации; он не загружается как часть таблицы событий.

`fixtures` — небольшой входной набор для самостоятельных проверок: 14 событий пяти пользователей и 16 рассылок. Строки событий перемешаны; порядок версий определяется по event_time.

В наборе есть повтор состояния, изменения отдельных атрибутов, возврат к прежнему состоянию, разные регистры домена, события на границе суток и рассылки до появления профиля. Выберите контрольные случаи, самостоятельно определите ожидаемый результат и сравните его со своим расчётом.

Таблицы `demo`, `fixtures` и необязательного `full` находятся в разных S3-префиксах и не должны смешиваться. Во время повторных расчётов исходные данные остаются неизменными.
